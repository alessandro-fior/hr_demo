② PL/SQL - Aumento del 10% per il dipartimento 60
Codice PL/SQL:

sql
DECLARE
    v_count NUMBER; -- variable to store row count
BEGIN
    UPDATE employees
    SET salary = salary * 1.10
    WHERE department_id = 60; -- update 5 rows
    
    v_count := SQL%ROWCOUNT; -- how many rows changed
    
    DBMS_OUTPUT.PUT_LINE(v_count || ' rows updated'); -- shows updated
    
    COMMIT; -- save changes

EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK; -- undo if error
        DBMS_OUTPUT.PUT_LINE(SQLERRM); -- shows error message
END; -- runs the block
Perché usare entrambi?
SQL = ottenere e modificare i dati

PL/SQL = aggiungere logica, cicli e automazione sopra

Insieme = meno chiamate al DB, codice più veloce e riutilizzabile
